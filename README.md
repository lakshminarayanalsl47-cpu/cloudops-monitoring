# CloudOps Monitoring Dashboard

## Overview

CloudOps Monitoring Dashboard is a cloud infrastructure monitoring solution built using HTML, CSS, JavaScript, and Flask. The project simulates real-world cloud operations by providing dashboards for server monitoring, AWS resource tracking, performance metrics, and alert management.

## Features

* Secure Login Authentication
* Dashboard Overview
* Server Monitoring
* AWS Resource Management
* CPU Usage Monitoring
* Memory Usage Monitoring
* Alert Tracking and Management
* Responsive User Interface
* Flask Backend API Integration

## How to Run

1. Clone the repository

git clone <repository-url>

2. Navigate to backend folder

cd backend

3. Install Flask

pip install flask

4. Start the Flask server

python app.py

5. Open frontend pages in your browser
